# Electricity consumption-production analysis

## Goal of the project
In this project, I execute exploratory data analysis on electricity consumption and photovoltaic (PV) production data sets for a detached house. The aim of the project are: 
1) Explore general patterns of consumption
2) Explore general patterns of PV production
3) Explore patterns of self-consumption of prodced PV electricity

## Data
- Gird data (obtained from electricity provider company)
- PV data (obtained from the PV plant's UI)

The two data sets span the period 1.1.2023 - 31.8.2026. The Grid data has a frequency of 1 hour. The PV data has a frquency of 1 day.

## Getting Started
It is best to excute the materials within a virtual environment. If you are using Linux: 
```bash
python3 -m venv .venv
source venv/bin/activate
```
Install the requirements:
```bash
pip install -r requirements.txt
```
